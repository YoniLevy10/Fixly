# Status Badge System

Statuses:

- pending
- accepted
- in_progress
- completed
- cancelled

---

# Rules

- Status must be recognizable instantly
- Text + color together
- Consistent across entire app
- Same terminology everywhere

---

# UX Principle

Users should never wonder:

"What is happening with my request?"

---

# Business Impact

Clear status systems reduce:
- support load
- cancellations
- user anxiety
