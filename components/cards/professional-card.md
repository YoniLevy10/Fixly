# Professional Card System

Purpose:

Core marketplace discovery component.

This card is one of the highest leverage UI elements in Fixly.

---

# Required Data

- displayName
- category
- city
- ratingAverage
- reviewCount
- isVerified
- avatar

---

# UX Rules

- Entire card clickable
- Large touch target
- Fast visual scanning
- Clear hierarchy
- Mobile-first spacing

---

# Priority Order

1. Trust
2. Category
3. Rating
4. Location

NOT the bio.

---

# Business Goal

Reduce hesitation.

The card exists to increase:
- profile opens
- request submissions
