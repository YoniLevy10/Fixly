# Request Card System

Purpose:

Central operational component.

Used by:
- customers
- professionals
- admins

---

# Required Data

- title
- status
- category
- createdAt
- customer/professional names

---

# UX Rules

- Status must dominate visually
- Timeline feeling
- One primary action
- Minimal clutter

---

# Status Priority

Visual emphasis:

1. pending
2. in_progress
3. completed

Cancelled should visually fade.

---

# Business Goal

Reduce operational confusion.
