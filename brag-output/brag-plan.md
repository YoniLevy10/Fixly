# Brag Plan: Fixly (v2 — 40s feature cut)

## What is this app?
Fixly is a Hebrew-first home-repair marketplace — find a verified pro fast, race to accept, track live like Wolt, covered by אחריות Fixly.

## The angle
Dinner gets a live map. Plumbing should too. This cut sells the full marketplace machine: request → match race → live track → trust stack → local coverage → logo.

## Hook (first 2-3 seconds)
Navy hero **זקוקים לתיקון?** → orange-edged **בקשה מהירה** slam.

## Key moments (the middle)
1. Category grid + featured pros carousel
2. Matching race: customer wait ↔ pro **קבל בקשה**
3. Live map + push **איש המקצוע בדרך!** + status chips + ETA
4. מאומת Fixly + stars + reviews
5. אחריות Fixly + city landing **אינסטלטור בתל אביב**
6. Platform stats count-up
7. Logo + תיקונים חכמים

## Outro / punchline
Fixly mark + **תיקונים חכמים** — hold.

## User flow worth showing
Hero → quick request → multi-match race → live tracking → trust → local SEO → scale proof → brand.

## Tone
- Preset: `app-store`
- Creative direction: Premium Hebrew marketplace launch — denser feature tour, still readable
- Interpretation: Faster cuts than v1, more product surfaces, higher marketing energy without chaotic tone

## Format: landscape — 1920x1080
## Duration: 40 seconds

## Visual identity (from the project)
- Background: `#F2F4F7`
- Accent: `#F59E0B`
- Brand primary: `#123563`
- Text: `#0F1729`
- Display/body font: Heebo
- Strongest visual: navy hero + live map with dual pins

## Share copy (draft)
Fixly — תיקונים כמו Wolt. בקשה מהירה, מקצוענים מאומתים, מעקב חי, ואחריות Fixly. תיקונים חכמים.

## Audio direction
- Role: warm energetic bed
- Music: `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3` (40s window)
- Music treatment: vol ~0.30; fade under final 1.5s
- Music cue guidance: bundled preset ~120 BPM; lock major beats near strong cues in 0–40s window
- Audio-reactive: subtle hero glow only
- SFX posture: moderate — cards, taps, success, logo
- Restraint: Hebrew copy readable over bed

## Storyboard

### Scene 1 — Hook — 4.0s (0–4)
Phone: hero **זקוקים לתיקון?** + subtitle + search + **בקשה מהירה** tap.
Sequential: title → CTA tap
Transition: slide → S2

### Scene 2 — Categories + featured — 5.0s (4–9)
**בחרו קטגוריה** 4 tiles beat-grid; then **אנשי מקצוע מומלצים** 2 featured cards with ★ + מאומת + זמין היום.
Sequential: cats then cards
Transition: wipe → S3

### Scene 3 — Match race — 5.0s (9–14)
Split/dual phones energy: amber **מחפשים מקצוענים...** → **3 מקצוענים קיבלו** · flip to pro **קבל בקשה** tap → assigned.
Sequential: wait → upgrade → accept
Transition: wipe → S4

### Scene 4 — Live track + push — 8.0s (14–22)
Map pins + route · **איש המקצוע בדרך אליך** · כמו Wolt · chip **בדרך** · lock-screen push **איש המקצוע בדרך!** · status row ממתין→אושר→בדרך→הושלם · ETA pill.
Sequential: map → copy → push → chips
Transition: soft → S5

### Scene 5 — Trust — 5.0s (22–27)
Pro card **מאומת Fixly** ★4.9 · reviews strip · **דרג את איש המקצוע**.
Sequential: badge → stars → review
Transition: wipe → S6

### Scene 6 — Guarantee + city — 5.0s (27–32)
Emerald **אחריות Fixly** body · then SEO frame **אינסטלטור בתל אביב** + city chips + **שלח בקשה עכשיו**.
Sequential: guarantee → city
Transition: wipe → S7

### Scene 7 — Scale — 4.0s (32–36)
4 metric tiles count-up: אנשי מקצוע · בקשות פעילות · עבודות שהושלמו · דירוג ממוצע.
Sequential: tiles
Transition: crossfade → S8

### Scene 8 — Outro — 4.0s (36–40)
Logo + Fixly + **תיקונים חכמים**. Music fade.
Sequential: logo → wordmark → tagline

**Music mood:** upbeat app-store marketing
**Audio summary:** Continuous bed under denser product tour; SFX on taps/cards/success/logo.
