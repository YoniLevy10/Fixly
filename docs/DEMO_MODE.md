# מצב הדגמה (Investor Demo)

## מצב נוכחי (לפני השקעה)

**דמו מופעל בכל הסביבות** — כולל `fixly.tech` בפרודקשן.

- באנר כתום, החלפת תפקיד לקוח ↔ בעל מקצוע, סיור 90 שניות
- 58+ אנשי מקצוע, 120+ בקשות, 250+ ביקורות (mock)
- ב־`fixly.tech` מוצגת האפליקציה המלאה (לא רק דף המתנה)

## Kill-switch (אחרי השקעה / נתונים אמיתיים)

```env
NEXT_PUBLIC_FF_DEMO_KILL=true
```

אחרי השינוי — redeploy. הערך הישן `NEXT_PUBLIC_FF_DEMO_DATA=false` **לא** מכבה יותר את הדמו (נשאר מ־marketing-ready).

## מה מופעל בדמו

- מעקב חי מדומה, ETA, התראות דפדפן
- באנר עם: החלפת תפקיד, **התחל הזמנה מלאה**, **סיור 90 שניות**
- זרימה: יצירה → אישור Pro → בדרך → עבודה → סיום → ביקורת

## מקומי

```bash
npm run dev
# כבוי מקומית:
NEXT_PUBLIC_FF_DEMO_KILL=true npm run dev
```

רענון קשיח: `Ctrl+Shift+R`. עם דמו אמור להופיע באנר "מצב הדגמה להצגה למשקיעים".

## סיור אוטומטי (~90 שניות)

1. **לקוח / בעל מקצוע** — החלפת תפקיד
2. **התחל הזמנה מלאה** — מול Pro `#1`
3. **סיור 90 שניות** — יצירה → אישור → מפה → סיום → ביקורת

### ידני

| שלב | מה לעשות |
|-----|-----------|
| 1 | **התחל הזמנה מלאה** (או `/request/new?professional=1`) |
| 2 | כתובת / תיאור → שליחה → מעקב |
| 3 | באנר → **בעל מקצוע** → אישור → בדרך → עבודה → סיום |
| 4 | באנר → **לקוח** → ביקורת |

```bash
curl -sS 'https://fixly.tech/api/health?verbose=1' | jq '.demoMode, .mode'

```
