# Request Flow Architecture

Purpose:

Minimize friction between intent and request submission.

---

# Flow

1. Select category
2. Browse professionals
3. Open professional profile
4. Submit request
5. Track progress

---

# Request Form Rules

- Minimal required fields
- Mobile-first input sizes
- Fast submission
- No long onboarding

---

# Required Fields

- title
- description
- optional images

---

# UX Goal

Fast action.

NOT paperwork.

---

# Marketplace Principle

Every additional field reduces conversion.
